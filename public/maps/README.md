# Polis local outlines

`ithaca.geojson` and `gainesville.geojson` are simplified extracts of OpenStreetMap ways retrieved September 27, 2026, via the public Overpass API. Coordinates remain geographic coordinates; presentation removes most small features and labels. The files retain OSM way identifiers for source review.

See [OpenStreetMap attribution and copyright](https://www.openstreetmap.org/copyright). These adapted GeoJSON databases are distributed under ODbL 1.0; this notice and their attribution are separate from the application source license. The files themselves are the offered machine-readable adapted database. The app displays attribution in each map.

Included layers: selected roads, waterways, green spaces and campus outlines. Ithaca has creek linework but no lake polygon in this small extract. This is a discovery backdrop, not a navigation or cadastral map. Venues are positioned by listing coordinates, not inferred from the illustration. No device or attendee locations are stored here.

To refresh: query OSM ways for the pilot area with major-road, waterway/water, park/grass/wood, and university tags; retain public source IDs and coordinates; map tags to `road`, `water`, `park` or `campus`; inspect the result and update the checked date. Review extent before adding venues outside the bundled area. Do not add private university information or user locations.
